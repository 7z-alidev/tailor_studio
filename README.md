# Tailor Studio | Pakistan's First Online Stitching Service

A modern web application built with **Next.js (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router with Turbopack)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)

---

## 🛠️ Features & Modern Components

- **Interactive Stitching Price Estimator**: Instant dynamic calculation of attire types, add-ons (piping, lining, express delivery), and turnkey price breakdown in PKR.
- **Doorstep Pickup & Booking Scheduler**: Integrated scheduling with time slot selection, custom sizing preferences, and instant reference ID confirmation.
- **Glassmorphic Navigation & Mobile Drawer**: Sleek responsive navigation bar with backdrop blur and smooth transitions.
- **Customer Reviews & Testimonials**: Verified Pakistani client feedback with rating stars and regional tagging.
- **FAQ Accordion**: Interactive answers for common queries about measurements, turnaround times, and free alteration guarantees.
- **Floating WhatsApp Concierge**: Instant direct chat button with pre-filled order context.

---

## 💻 Getting Started Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   npm run start
   ```
